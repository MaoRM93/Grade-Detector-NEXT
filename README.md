再也不用每天刷教务系统了！这个小工具帮你自动查成绩（含下载链接）

成绩更新第一时间通知你，排名变化心中有数，优雅又省心。

考完试，最让人头疼的是什么？

不是考试，不是论文——而是 每天反复登录教务系统，一遍遍刷新成绩页面，生怕错过任何一门出分。

本公众号隆重推出一款适配macOS与Windows（以后支持！！）的成绩排名自动检测工具，安装后默默在后台工作，出分了就发通知告诉你，省下大把刷网页的时间。


它是怎么工作的？
本程序 会按照你设定的时间间隔，自动登录教务系统查询成绩和排名。

一旦检测到 新出成绩 或 排名变化，立即通过 macOS 原生通知或 Windows 原生通知推送到你的桌面。（好刺激。。。）

也支持简洁模式！仅提示「您有成绩或排名更新」这几个字，保护隐私，保护心灵。
你唯一需要做的事：看一眼通知，继续做自己的事。

核心功能一览
自动监测
支持 成绩监测 和 排名监测，可独立开关。
可设定监测时间窗口（如 08:00–22:00），深夜不打扰。
监测间隔可自定义，建议不低于 300 秒。（系统也不允许设置小于299秒，避免对学校服务器造成过大的负担）

通知推送
详细模式
：直接在通知中显示课程名、绩点、专业排名、班级排名变化。
简洁模式
：仅提示「您有成绩或排名更新」这几个字，保护隐私，保护心灵。

排名可视化
主界面实时展示 专业排名 和 班级排名，无需登录教务系统即可查看。
开机自启动
通过 macOS 原生登录项机制实现，可在「系统设置 → 通用 → 登录项与扩展」中随时管理。
通过 Windows 自启动实现，可在 App 内直接管理。
菜单栏图标
在顶部菜单栏或底部托盘显示小图标，点击可快速打开主界面或退出程序。
深色模式适配
自动跟随系统深色/浅色模式切换，夜间使用不刺眼。


如何使用？
macOS 端
下载 GradeMonitor.app，拖入「应用程序」文件夹。
首次打开时，请在 Finder 中右键点击 App → 选择「打开」，确认运行。
在界面上方填写学号和密码（可勾选记住密码）。
勾选需要监测的项目，设置时间范围和间隔。
点击「启动自动监控」，然后关闭窗口——程序会在后台默默工作。
等待通知。
关闭窗口不会退出程序。如需彻底退出，在 macOS 端，请通过菜单栏图标选择「退出」或按 Command + Q。在 Windows 端，请通过右键托盘图标退出。
